# StudyOS

StudyOS é uma plataforma de estudos desenvolvida em Python que reúne matérias como Matemática, Física, Química, Português, História e Espanhol.

O projeto permite praticar exercícios, acompanhar o progresso e revisar conteúdos enquanto também serve como projeto prático para aprendizado de Python.

## Funcionalidades

* 📚 Múltiplas matérias
* 📝 Exercícios e perguntas
* 📊 Sistema de progresso
* 🔄 Revisão de conteúdos
* 💾 Salvamento de dados

## Tecnologias

* Python
* JSON
* SQLite

## Objetivo

Desenvolver uma ferramenta de estudos enquanto pratico conceitos de programação e evoluo meus conhecimentos em Python.
